# 📈 Stock Market Trend Analysis Dashboard

A professional stock market dashboard built with Python and Streamlit.

🌐 **Live App:** [Click Here to Open](https://stock-dashboard-maivizhi-2026.streamlit.app)

---

## 📌 Features

- 📈 Real-time stock data from Yahoo Finance
- 🕯️ Candlestick charts with Bollinger Bands
- 📊 Moving Averages (MA20 & MA50)
- 💹 RSI — Relative Strength Index
- 📉 MACD — Moving Average Convergence Divergence
- 📊 Trading Volume Analysis
- 🔍 7 stocks: AAPL, TSLA, GOOGL, MSFT, AMZN, NFLX, META
- 📅 Custom date range selection

---

## 🛠️ Tools Used

| Tool | Purpose |
|---|---|
| Python | Programming Language |
| Streamlit | Web Dashboard |
| yfinance | Stock Data |
| Plotly | Interactive Charts |
| Pandas | Data Handling |
| NumPy | Calculations |
| ta | Technical Indicators |

---

## 🚀 How to Run

pip install streamlit yfinance plotly pandas numpy ta

streamlit run app.py
